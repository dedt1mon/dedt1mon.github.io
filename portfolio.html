Политика конфиденциальности

Это политика личного портфолио DedTimon / Дед Тимон на dedt1mon.github.io. Здесь описано, что происходит с данными при просмотре сайта и переходе по его ссылкам.

Просмотр сайта и поиск

Сайт самостоятельно не собирает персональные данные посетителей. Здесь нет регистрации, личного кабинета, форм обратной связи, заказа или оплаты. Для просмотра работ не нужно сообщать имя, телефон или электронную почту.

Поиск по проектам выполняется только в вашем браузере. Введённый текст не отправляется автору или на сервер.

Cookies, хранилище и аналитика

В текущей версии код сайта не устанавливает cookies и не использует localStorage или sessionStorage. Счётчики аналитики, рекламные трекеры и инструменты записи действий посетителей не подключены.

Изображения, видео и шрифты

Материалы портфолио и шрифты загружаются с домена этого сайта. Видео открываются в обычном браузерном плеере. Встроенных плееров YouTube, сторонних виджетов и внешних библиотек, загружаемых при просмотре страницы, нет. Запросы файлов обрабатывает хостинг сайта.

Хостинг GitHub Pages

Сайт размещён на GitHub Pages. Согласно документации GitHub Pages, хостинг записывает IP-адрес посетителя в целях безопасности — независимо от наличия аккаунта GitHub. Поэтому отсутствие собственного сбора данных на сайте не означает отсутствия технической обработки у хостинга.

Подробнее об обработке данных хостингом — в политике конфиденциальности GitHub.

Внешние ссылки

На сайте есть ссылки на Telegram, WhatsApp и YouTube. Это обычные переходы во внешние сервисы, а не встроенные интеграции. При переходе вы покидаете сайт; дальнейшая обработка данных, использование cookies и работа с вашим аккаунтом определяются правилами выбранной платформы.
